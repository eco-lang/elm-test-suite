# LaTeX Conventions

How chapters are written in LaTeX. The layout environments live in `defn.sty`;
the language's own notation lives in the book's `macros.sty`, generated by
stage 02 from `notation.md`. Form rules (what goes where) are in
`../definition-style.md`; this file only says how to typeset them.

## Files

| File | Role | Edited By |
|------|------|-----------|
| `defn.sty` | Layout: rule groups, rules, comments, grammar, object tables, derived forms | Nobody per book; change it here for every book |
| `book-template.tex` | Master document skeleton | Copied and filled by stage 08 |
| `chapter-preview.tex` | Compiles one chapter standalone | Nobody |
| The book's `macros.sty` | Every registered symbol, metavariable and judgment | Generated by the architecture stage from `notation.md`; never by hand |

## Chapter Files

- One file per grid cell or appendix, named as in the book plan
  (`syntax-core.tex`, `static-modules.tex`, `appendix-derived-forms.tex`).
- A chapter file starts with `\chapter{...}` and a `\label{ch:<name>}`. It has
  no preamble and no `\begin{document}`.
- Line one to the first `\chapter` may hold only the value brief comment block
  (see `../value-framework.md`).

## Environments and Commands (from defn.sty)

| Need | Write |
|------|-------|
| Terminal (reserved word, symbol) | `\kw{let}`; braces as `\kw{\kwlb}` and `\kw{\kwrb}` |
| Metavariable | `\mv{exp}`, works in text and maths |
| Class or semantic domain | `\cls{TyVar}` |
| First and second options | `\opt{...}`, `\optt{...}` |
| Rule group heading with boxed judgment | `\rulegroup{Expressions}{C \vdash \mv{exp} \Rightarrow \tau}` |
| A rule | `\defnrule[r:label]{prem \premsep prem}{concl}`; axiom: empty premises; extra premise line: `\\` |
| Refer to a rule | `\ruleref{r:label}` prints "(n)" |
| Comments block | `\begin{rulecomments} \rcomment{r:label} text \end{rulecomments}` |
| Grammar figure body | `\begin{grammar} \gprod{lhs}{rhs}{label} \galt{rhs}{label} \gnote{(n >= 1)} \end{grammar}` |
| Object figure body | `\begin{objtable} \objrow{var}{Class}{description} \objdef{var}{Class}{set expression} \end{objtable}` |
| Derived forms table body | `\begin{derivedforms} \dform{derived}{equivalent} \end{derivedforms}` |
| Stated property | `\begin{property} ... \end{property}` |

Wrap grammar, object and derived-form bodies in a `figure` with a `\caption`
in the exemplar's style ("Grammar: Expressions, Matches, Declarations and
Bindings", "Simple Semantic Objects") and a `\label{fig:<name>}`.

## Label Scheme

| Kind | Form | Example |
|------|------|---------|
| Chapter | `ch:<file name>` | `ch:static-core` |
| Section | `sec:<chapter>-<slug>` | `sec:static-core-closure` |
| Figure | `fig:<slug>` | `fig:grammar-expressions` |
| Rule | `r:<phase>-<class>-<slug>` with phase `s` or `d` | `r:s-exp-let` |
| Restriction (syntactic or further) | `res:<level>-<slug>` with level `core`, `modules` or `program` | `res:core-no-float-pattern` |
| Derived form | `df:<slug>` | `df:if` |
| Entry of the initial basis | `b:<Module>.<name>`: a type (with its constructors) or a value; an operator under the hidden variable it stands for | `b:Basics.modBy`, `b:Maybe.Maybe` |

Labels are unique across the whole book. Stage 07 checks this.

Rules carry their label in `\defnrule`. Every other citable item takes one with
`\citelabel{label}`, placed where the item is stated: after `\item` for a
restriction, at the start of the first argument of `\dform`, after the name in
a static basis table. `\citealso{label}` marks a further place that belongs to
the same item (the dynamic basis row of a value, the value rows of a type's
constructors). Neither prints anything. The web edition gives each label a
page at an address made from it, so a label, once published, does not change;
the words of a slug are the subject of the item, never its position.

## Notation Discipline

- Every registered symbol is written with its `macros.sty` command, never as
  raw LaTeX, so a change in `notation.md` changes the whole book.
- A symbol not in the registry is not used. Add it to `notation.md` (stage 02
  owns the file) and regenerate `macros.sty` first.

## Preview

Before writing a chapter to `definition/tex/`, compile it standalone in the
scratch folder `definition/preview/`, with the draft chapter file in that
folder. List the scratch folder first in `TEXINPUTS`, so the draft is used in
place of any copy already in `definition/tex/`, which supplies `macros.sty`
and the other chapters. From `definition/preview/`, this `shared/latex` folder
is `../../pl-definition-writer/shared/latex`.

```
TEXINPUTS=.:../tex:../../pl-definition-writer/shared/latex: \
  pdflatex -interaction=nonstopmode -halt-on-error -jobname=preview \
  "\def\chapterfile{<chapter name>}\input{chapter-preview.tex}"
```

Run it twice so references resolve, then write the chapter to
`definition/tex/` and delete `definition/preview/`. Use the engine
from `../run-config.md` in place of `pdflatex`. A preview must finish with
no errors and no undefined references other than cross-chapter ones.
