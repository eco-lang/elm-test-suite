# Exemplar Index

Where to see each form rule in the exemplar, *The Definition of Standard ML
(Revised)*, Milner, Tofte, Harper and MacQueen, MIT Press 1997. The PDF's path
is in `run-config.md`. The book is copyright and is never copied into a chapter:
read it for form, never for content or wording.

Page numbers are **PDF pages** (pass them to the Read tool's `pages`
parameter). Printed page = PDF page minus 14. Load one range at a time, only
for the rule you are applying.
