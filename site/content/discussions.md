# Discussions

The tests and their results are discussed in the [Tests category of the repository's GitHub Discussions]({{categoryUrl}}). A discussion is about a test when its title holds the test's key in brackets, `[t:elm/CompilerIssue2281LongLineListTest]`, about a whole project with `[p:elm]`, or about a tag with `[tag:elm19-bug]`; the Discuss link on each test's page starts one with the key in place, and the discussion is then shown on that page.
