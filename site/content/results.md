Each test is a real Elm program: the suite compiles it with each compiler, runs it, and checks its output against the expected output in its comments. The tests tagged [`elm19-bug`](/tags/elm19-bug) and [`elm19-bug-fix`](/tags/elm19-bug-fix) expect the correct behaviour where Elm 0.19.1 has a bug, so they fail under 0.19.1 by design.

The site also carries [*A Standard Definition of Elm?*](/standard), a formal definition of the language with a page for every rule.

Each test, project and tag has a Discussions section: start a discussion of a test on GitHub from its page, and it is shown there. See [all the discussions of the tests](/discussions).
