## Seams Checked Without Finding

- Operator tables: `Dom \OTstat = Dom \OTdyn` = the operators of fig:core-fixities; schemes and statuses in fig:static-basis-operators agree with the hidden variables' values in fig:dynamic-basis-operators (`::` with status c and constructor value `::`, arity 2); `smops(Basics) = Dom OTstat \ {::}`, `smops(List) = {::}` match the figure's footnote; r:sm-item-op and r:dm-expitem-op both bind nothing.
- E_0: static (Appendix C, `(emptymap, TE_0, VE_0)`, reached through pi_0 and TE_List/VE_List) and dynamic (Appendix D, `(emptymap, VE_0)`, premise of r:dm-module) agree; E_K and E_Task are built on it.
- Dynamic interfaces: Appendix D's CE (Never -> empty map; abstract types in no CE) agrees with static closedness (Never keeps JustOneMore in its type structure, abstract types have empty type-structure VE), so `Never(..)` elaborates and evaluates, importing nothing, and `Array(..)` does neither. The property of sec:dynamic-modules-compound holds for ME_0.
- Default copy against programs: Dflt (Int for each bound number variable) is exactly the default copy's instance; r:p-dyn-main reads VE(main) from it; dynamic-modules' bullet keeps the default copy's name.
- Task.perform/attempt: Appendix C (hidden identifiers), Appendix D (VE_Task binds `command`, `Perform`; BasVal list), effects (fig:effects-apply row for Task.command and the paragraph after it) agree word for word in substance.
- JSON numbers (A88): effects sec:effects-simple, r:e-enc-float, r:e-enc-float-null, r:e-dec-int, r:e-dec-float, the Property and fig:effects-port-table agree with A88 and with Appendix E's requirement bullet, Values at the Boundary and Known Divergences; decoding beyond the finite floats agrees with fl of Appendix D.
- Bytes: both port tables have the same row; Appendix E has the matching rows.
- Platform and host: every use in Chapters 3 to 9 and Appendix E fits the Introduction's definitions.
